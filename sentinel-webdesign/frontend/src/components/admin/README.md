# Administration Domain Pod

**Squad Owner:** `@sentinel-org/platform-admin-team`

## Responsibilities
- User account provisioning and role-based access control (RBAC).
- Declarative YAML configuration inspection, validation, and hot-reloading.
- System maintenance window broadcast management.

## Components
- `AdminManagement.jsx`: User roster, LDAP directory sync, and system settings.
- `YamlConfigManager.jsx`: Declarative YAML viewer and schema validator.
