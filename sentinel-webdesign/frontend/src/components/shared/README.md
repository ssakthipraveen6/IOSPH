# Shared UI Primitives

**Squad Owner:** `@sentinel-org/frontend-core-team`

## Responsibilities
- Atomic, reusable design tokens and UI building blocks.
- Unified status pills, indicators, and vectors.
- Enterprise maintenance banners and alert notices.

## Components
- `StatusBadge.jsx` / `StatusBadge.tsx`: Authorized status pill with `@sentinel/shared-constants` mapping.
- `Sparkline.jsx` / `Sparkline.tsx`: SVG vector trendline with min/max auto-scaling.
- `MaintenanceNotice.jsx`: Maintenance banner and badge widgets.
