# Analytics & Telemetry Domain Pod

**Squad Owner:** `@sentinel-org/telemetry-analytics-team`

## Responsibilities
- PowerBI executive KPI analytics and report generation.
- Historical time-series telemetry inspection and granular component metrics.
- AI log anomaly pattern visualization and regression prediction.

## Components
- `RcaDashboard.jsx`: Root Cause Analysis engine with multi-layer flow graphs.
- `PowerBiDashboard.jsx`: Executive summary reports and SLA metrics.
- `AiLogPerformance.jsx`: Real-time AI engine anomaly recognition feed.
- `MetricsDetail.jsx`: Component telemetry charts with custom thresholds.
- `CustomChart.jsx`: Reusable SVG multi-series time-series charting component.
