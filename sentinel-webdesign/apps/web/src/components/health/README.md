# Health Domain Pod

**Squad Owner:** `@sentinel-org/platform-health-team`

## Responsibilities
- High-level system health scoring (0–100 index).
- Component health rollups across Applications, Ingress (AVI), Compute, Storage, and Identity.
- Multi-application Unified Health Matrix and Colleague Matrix status views.

## Components
- `HealthOverview.jsx`: Primary enterprise service map and live topology status board.
- `UnifiedHealthMatrix.jsx`: Multi-layer matrix view tracking per-application status.
